# One Letter for Your Day: O

My day, in a single letter: **O** — for **overcaffeinated**.

It started with one cup of coffee, then a second to "wake up properly", then a third because the code still wasn't finished, then a fourth because by then the hands were already shaking and stopping felt harder than continuing. By 3 a.m. my heart was drumming against my ribs, my eyes were wide open and would not close — and somehow the work kept shipping anyway: one more commit, one more fix, one more small win, all powered by caffeine and stubbornness in equal measure.

O fits the word in shape as well as sound: round like the coffee ring left on the desk, round like wide-open eyes at 3 a.m., and the long open "oh" of someone realizing they have had far too much coffee and are going to finish the job anyway.

## Run it

```bash
python3 main.py
```

Writes exactly one byte — `O`, no newline — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` if set), then reads it back to prove it.
